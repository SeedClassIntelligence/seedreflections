# Billing & Tiers

The platform defines three subscription plans:

1. **Free Plan** ($0):
   * 50 reflections limit.
   * Local browser storage.
   * Basic context handoff.
2. **Pro Tier** ($9/mo):
   * 250 reflections limit.
   * Persistent database cloud backups.
   * Custom LLM provider support.
3. **Master Tier** ($20/mo):
   * Unlimited reflections.
   * Priority queues and developer API access.
