# File Manifest

* `server.py`: API Server & DB controller.
* `consumer-dashboard.html`: The central workspace dashboard.
* `auth.html`: Sign-in and Stripe gateway client.
* `index.html`: Product home page.
* `_redirects`: Netlify rewrite routing configuration.
* `js/platform.js`: Shared frontend services.
* `seeds.json`: Database file.
* `project-handoff/`: Folder containing documentation markdown specs.
