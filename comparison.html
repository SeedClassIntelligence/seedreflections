The problem

AI work is easy to create and hard to keep usable

The problem is not a shortage of conversations. It is turning months or years of scattered work into something you can understand, verify, and continue.

◫

Fragmented history

Useful work lives across assistants, documents, exports, folders, and copied threads. The context is separated even when the mission is the same.

{ }

Unreadable exports

Platform exports may preserve the data without making it human-usable. Large JSON archives and long transcripts still need structure, titles, relationships, and search.

✓

Unreviewed interpretation

AI can identify possible ideas, decisions, tasks, constraints, and drift. Those interpretations should remain proposals until a person accepts, defers, or rejects them.

The SeedReflections workflow

One connected path from scattered history to active work

The advantage is not a single feature. It is the governed flow between ingestion, understanding, review, and continuation.

1. Bring work in

Upload platform exports and common documents, paste a conversation, select authorized local folders through SeedBridge, or receive content through an approved integration.

  • JSON is a first-class ingestion source
  • Large archives become usable records
  • Source identity and lineage are preserved

2. Preserve and understand

Normalize the material into a searchable Library and identify candidate conversations, ideas, decisions, tasks, constraints, evidence, and drift.

  • Original source remains accessible
  • Related material can be found across sources
  • Insufficient evidence can remain unresolved

3. Review before authority

SeedReflections proposes; the user decides. Accept, defer, or reject candidate interpretations before they become durable project context.

  • No silent promotion into project truth
  • Evidence stays linked to the finding
  • Human judgment remains visible

4. Continue the work

Turn accepted material into plans, briefs, reports, task sets, and notes inside the Workspace—with status, versions, relationships, and export.

  • Ask questions across approved sources
  • Move from insight to an artifact
  • Return without rebuilding context
The model layer

Works with the model you choose

SeedReflections is not another assistant to switch to. It sits over your archive and uses a model for the jobs that need one, so the model can change without your work moving.

⇄

Chosen per task

Extraction, classification, summarizing, research, planning, writing, and code each go to a model suited to the job, from the models your deployment and plan allow. Local open models such as DeepSeek, Qwen, and Llama can be used alongside hosted providers.

⌘

Your own key

Bring a private API key for the provider you prefer. It is kept in your operating system keychain, or for the current session only, and it is never written into a backup.

✓

Limits you can see

Plans set limits on reflections and seeds, and the platform enforces monthly AI budget caps with a kill switch. Whatever a model proposes stays a candidate until you accept it.

Model-assisted features need a model to be configured for your deployment. Which providers are available depends on that deployment.
