SeedReflections

Connect this extension to your own SeedReflections account. In SeedReflections, open Settings, create an API connection, and copy its address and token here.

The extension will ask Chrome for permission to talk to that one address only. Your token stays in this browser.

The report lists page element names and counts only. It contains none of your message text.

Reads only the conversation on screen, only when you click. Nothing runs in the background.
