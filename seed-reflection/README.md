# Seed Reflection

> Find every lost idea in your AI conversations.

**Seed Reflection** is the consumer face of the SRT-1 (Seed Reflection Tool) system. It lets anyone — not just developers — mine their AI conversations for abandoned ideas and pick them back up.

Built on the same core IP as the [SRT-1 Code Indexer](../website/index.html): `srt.py` and `seed_signature_engine.py`. Same Seed Signatures. Same SCIA architecture. Different audience.

## Quick Start

Open `index.html` in a browser. No build step. No server required.

To use the Reflect mode, you need an Anthropic API key. Enter it once — it's stored in your browser's localStorage and never sent anywhere except Anthropic's API.

## The 7 Snippets

| ID | Name | When to use |
|---|---|---|
| `SCIA-REFLECT-FULL` | Full Seed Reflection | After any long conversation |
| `SCIA-COHERENCE` | Quick Coherence Check | Mid-conversation drift detection |
| `SCIA-RECOVER` | Thread Recovery | Returning after time away |
| `SCIA-HARVEST` | Multi-Platform Harvest | Extracting ideas from any conversation |
| `SCIA-PLANT` | Project Seed Plant | Starting a new project |
| `SCIA-CONTINUE` | Continue From Last Session | Resuming across chat windows |
| `SCIA-IMPORT` | JSON Import Analysis | Triaging exported conversation data |

These snippets work in **any** AI platform — ChatGPT, Claude, Gemini, Copilot, or any other. Copy them from `snippets.html` and paste them into any chat.

## API Scripts

### `api/parse_export.py`

```bash
# Parse a ChatGPT export
python api/parse_export.py conversations.json

# Parse a Claude export, write to file
python api/parse_export.py claude_export.json --output parsed.json --format json

# Parse a ChatGPT zip
python api/parse_export.py chatgpt_data.zip
```

### `api/extract_seeds.py`

```bash
# Extract seeds from a transcript (offline, no API key needed)
python api/extract_seeds.py transcript.txt

# Get JSON output
python api/extract_seeds.py transcript.txt --format json

# From stdin
echo "User: I want to build a mobile app\nAssistant: Sure!" | python api/extract_seeds.py -
```

## Seed Signature

Every reflection report generated by this app carries a **Seed Signature** — a provenance block that records what was found, when, and how.

```
---SEED-SIGNATURE---
Type:        SCIA-REFLECT-FULL
Timestamp:   2026-03-15T14:32:08Z
ID:          SR-L8KQ2MNP
Seeds Found: 7
Abandoned:   4
Drift Points: 2
Platform:    ChatGPT
---END-SIGNATURE---
```

This is not decorative. It is the SCIA protocol in action — traceability built into every output.
