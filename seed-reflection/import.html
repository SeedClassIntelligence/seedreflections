ChatGPT Export

Download your data from OpenAI's settings page.

  1. Open ChatGPT → Settings → Data Controls
  2. Click "Export data"
  3. Download the zip file from your email
  4. Upload the zip or extract conversations.json
🟣

Claude Export

Download your conversations from Anthropic's privacy portal.

  1. Visit claude.ai → Settings → Privacy
  2. Click "Export conversations"
  3. Download the JSON file
  4. Upload it here
🔒

Your conversations stay private.

All file parsing happens entirely in your browser using JavaScript. Nothing is uploaded to any server. Your conversations are never stored anywhere. When you click "Reflect," the conversation text is sent to Claude via the Anthropic API to generate your report — that is the only external request made.

No API key set — required for reflection
